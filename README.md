# 出張おみやげ帳

講習会の出張先（徳島・広島・札幌・金沢・仙台・大阪・名古屋・沖縄）ごとに、お土産の候補と買う場所、写真をまとめるページです。

- 名物ごとに「買ってきて」「買った」の印を付けられます
- 「2人用の帳面を作る」を押すと合言葉つきのリンクができます。相手に一度送れば、2人の印と写真が自動で同じになります（Firebase の Firestore に保存）
- 写真は撮影場所か撮影日から、どの出張先の写真かを自動で振り分けます

ファイル:
- `index.html` … ページ本体
- `firestore.rules` … データベースの決まり（合言葉を知っている人だけが読み書きできる）。Firebase コンソールの「ルール」に貼って使う
